# Install script generator

::: warning Third-party projects, built for HestiaCP
The generators below are maintained by third parties for **HestiaCP**, the
project TulioCP was forked from. They emit HestiaCP installer command lines,
which are close to but not identical to TulioCP's. Treat their output as a
starting point and check it against `bash tulio-install.sh -h` before running
it. Report problems with them to their own repositories, not to TulioCP.
:::

These are some install script generators created by the community:

- [hestiacp-scriptline-generator](https://github.com/gabizz/hestiacp-scriptline-generator)

  Tiny online app aimed to generate the necessary command for an unattended installation.

- [HestiaCP-Command-Creator](https://github.com/turbopixel/HestiaCP-Command-Creator)

  Vue.js based web app to generate the command line for an unattended installation.

TulioCP's own [install script generator](/install) is the only one kept in sync
with the current TulioCP release.
